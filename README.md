# Charter Hunter

Читает Telegram-каналы с чартерными билетами, разбирает посты через `claude -p` (модель Haiku, по подписке Claude Code) и рассылает через Telegram-бота всем его подписчикам дайджест новых билетов: по направлениям, сначала дешёвые, при равной цене — ближайшие. Прошедшие даты и уже показанные билеты отбрасываются.

## Настройка (один раз)

1. `cp .env.example .env` и заполнить ключи:
   - `TG_API_ID`, `TG_API_HASH`: https://my.telegram.org → API development tools
   - `TG_BOT_TOKEN`: создать бота у [@BotFather](https://t.me/BotFather) командой `/newbot`
2. `uv run hunter login`: ввести телефон и код из Telegram. Сессия сохранится в `data/telegram.session`.
   Каналы по-прежнему читаются через ваш личный аккаунт, а рассылает дайджест бот.

## Подписчики

Чтобы получать дайджест, нужно открыть бота и нажать «Старт» (`/start`); отписаться — `/stop`.
Подписки подхватываются при каждом `hunter run`. Telegram хранит неполученные сообщения бота только 24 часа,
поэтому если дайджест запускается реже, держите запущенным `uv run hunter bot` — он сразу отвечает на `/start` и `/stop`.
Кто заблокировал бота, удаляется из подписчиков автоматически.

## Запуск

```bash
uv run hunter run            # собрать, разобрать, разослать дайджест подписчикам бота
uv run hunter run --dry-run  # только напечатать в консоль
uv run hunter run --all      # все актуальные билеты, а не только новые
uv run hunter bot            # слушать бота и сразу принимать подписки
```

Каналы, города вылета и прочее настраиваются в `config.yaml`. База лежит в `data/hunter.db`.

## Поиск по базе

Ищет среди всех собранных актуальных рейсов, без обращения к Telegram:

```bash
uv run hunter search -d 05.11 -t "Анталья,Пхукет" --max-price 150000
uv run hunter search -d 05.11 --days 3 --from Астана --roundtrip
uv run hunter search -t гоа --min-price 100000 --send   # результат в «Избранное»
```

- `-d/--date` — примерная дата вылета (`05.11`, `05.11.2026`, `2026-11-05`), `--days` — ± дней (по умолчанию 5)
- `-t/--to`, `--from` — города через запятую, можно частично: `анта` найдёт Анталью
- `--min-price`, `--max-price` — диапазон цены в тенге
- `--oneway` / `--roundtrip` — только в одну сторону / только туда-обратно
